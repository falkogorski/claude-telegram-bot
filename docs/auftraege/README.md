# Eingang fuer Auftraege und Befunde

**Hier ablegen, was die Bau-Sitzung lesen soll.**

**Warum nicht iCloud:** macOS schuetzt vier Orte besonders — Schreibtisch,
Dokumente, Downloads **und iCloud Drive**. Fuer Terminal-Werkzeuge sind sie
ohne ausdrueckliche Systemfreigabe gesperrt; gemessen am 28.08.2026 scheitert
dort schon ein blosses Auflisten mit `Operation not permitted`. Dass frueher
Dateien aus iCloud ankamen, lag daran, dass die **App** sie geoeffnet und
hineingereicht hat — nicht an einem eigenen Zugriff.

**Dieser Ordner liegt ausserhalb der Schutzzone** und ist damit ohne
Systemeingriff erreichbar. Zusaetzlicher Gewinn: Was hier liegt, ist
**versioniert** und geht nicht verloren.

**Wie ablegen:** im Finder hierher ziehen, im Speichern-Dialog hierher sichern,
oder im Terminal kopieren.

**Was hierher gehoert:** Auftraege, Befunde, Gegenpruefungen, Nachsaetze.
**Was nicht:** Geheimnisse jeder Art — Schluessel, Token, Kennwoerter,
Klientendaten. Der Ordner ist versioniert; was hier landet, landet auf GitHub.
